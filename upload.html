Columns: Name, Difficulty, Question, Answer, Round, isDoubleJeopardy (optional Image URL column, if you already have an image hosted somewhere — otherwise leave it blank and attach photos afterward from the saved-games list below). Round is just 1, 2, or 3 — a category's left-to-right position on the board is simply the order its rows first appear in the file, so keep all 5 rows of a category together. For Final Jeopardy, put the literal text Final Jeopardy in the Round column instead, with the category in Name, the clue in Question, and the response in Answer. Each round needs exactly 5 categories with 5 questions (difficulty 1-5) apiece; rounds 1-3 are all optional but whichever are present must be complete.
Starts with the same 3-round, 5-category, 5-question layout as an uploaded game, filled with placeholder text — you'll rename categories and fill in each question in the editor that opens next.
